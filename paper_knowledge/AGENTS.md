# Paper Knowledge Rules

- Agent-facing content in this directory is English.
- This directory is intentionally independent from the main research state.
- The only planning integration point is `ENTRYPOINT.md` plus generated briefs.
- Store compact facts, not full papers.
- Do not download papers, crawl repositories, or read broad directories.
- Use explicit user-provided scopes for all imports.
- CLI programs print exactly one final `OK ...` or `ERROR ...` line.
- Keep graph updates deterministic and reviewable.
