# Experiment records

- Keep at most one active experiment.
- DRAFT creation opens no Python; planning opens only reasoned, budgeted `planning_reads`.
- Use only the four main headings: `Hypothesis`, `Method`, `Conclusion`, and `Issues and Next Direction`.
- Lock the plan before implementation and never edit locked success criteria after results are visible.
- Read completed experiments through `DIGEST.md`; open a full record only by exact experiment ID.
