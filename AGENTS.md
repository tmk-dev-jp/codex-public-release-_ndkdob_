# Repository rules

- English outside `human/`.
- Research: start at `research/CONTEXT.md`; read active scope only.
- Maintenance: resume maintenance/HANDOFF.md; finish edits/checks; no turn limit.
- Supervisor: delegate by default; pass paths/constraints, not transcripts. Workers explore; return concise evidence. Own routing/integration/reporting; preserve authorization.
- Judgment: follow `automation/INDEPENDENT_JUDGMENT.md`; user/peer approval is not evidence.
- List paths first. DRAFT reads no Python; planning/implementation use budgeted read lists.
- Never recurse into data/artifacts/reference payloads/completed experiments.
- Research: max 3 phases/turn; only requested `$run-one-unattended-loop` or `$run-one-agent-led-loop` spans an experiment.
- Scripts own transitions/execution/artifacts/hashes/finalization/validation.
- One active experiment; one coherent method comparison.
- Plan from goal; search 2-3 close hits. Keep controls; no exploratory grids/seed searches.
- Gate subagents; delegate only on its action. Planning/audit: frontier/high; implementation: locked profile.
- Read-only auditors; one worker/phase; no panels/retries/fallback. Save output; close if supported.
- CLI: one `OK ...`/`ERROR ...` line; no logs/telemetry/retries.
- Reuse, stdlib/deps, minimal code; preserve scientific checks.
- User references: search/download/OCR/full papers need approved scope.
