# 研究判断を委任する1ループ

通常なら人間に戻す新規性・設計・計画承認・結果解釈を、専用の研究判断サブエージェントに委任する別経路です。既存の通常モード、無介入モードの停止条件は変えません。

```text
$run-one-agent-led-loop を使い、研究上の判断もサブエージェントに委任して、研究実験を1ループ完了してください。
```

起動用の文面は`automation/AGENT_LED_LOOP_PROMPT.md`です。専用ルーターは`scripts/next_agent_led_loop_step.py`、進行記録は`STATE.agent_led_loop`です。対象IDを保持し、実験確定・研究記憶・方針更新まで進めたら終了します。次の実験は作りません。この機能の作成依頼だけでは研究を開始しません。

| 判断待ち | 新しい経路 |
|---|---|
| 新規性の根拠不足・判断の難しさ | 研究判断エージェントが範囲内の近接研究を確認し、根拠を保存する |
| 高リスク・既知手法の再現に近い | 同じ目標に沿って実験計画を実質的に修正し、再固定・独立監査へ戻る |
| 計画監査のwarn | 制約を根拠付きで受け入れるか、計画を修正する |
| 計画監査のfail | 合格扱いにせず、修正後の計画を新たに独立監査する |
| 設計上の未決事項 | 問い・代替説明・識別に必要な証拠に沿って具体案を決める |
| 結果の曖昧さ・観測不足 | 固定した判断規則のまま支持・棄却・不確定を判断し、最終化へ進める |

判断には`gpt-6-astra`・highを使用し、元の会話を渡さず、必要資料と問いだけを渡します。入力、出力、受理記録を`review/decisions/<ID>/`に保存し、出力を人間の解釈として記録しません。新規性確認は類似研究2〜3件のタイトル・abstract・検索スニペットまでです。

計画・実装・完全性の独立監査は残ります。警告の受入れと監査結果そのものを区別し、計画を変えたら再監査します。結果が不確定でも、根拠と限界を明示して1ループを完了できます。成功を装うために指標や判定規則を変えることはありません。

無限の再判断を防ぐため、対象ごとに判断エージェントは最大6回、計画修正は最大2回です。同じ依頼に別のエージェントを起動し直しません。研究目的や必要データが未提供、権限・計算予算が不足、実行や完全性監査が失敗、判断エージェントが利用不能の場合は、その理由を保存して停止します。full学習の追加承認や、論文全文・広範な外部調査の許可は別に必要です。
