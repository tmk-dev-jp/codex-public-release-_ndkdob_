# 既存の研究ディレクトリから移行する

## 依頼方法

元の研究ディレクトリとは別の場所にテンプレートを展開し、テンプレート側でCodexを開きます。実験が進行中のテンプレートには移行せず、別のコピーを使ってください。

```text
$migrate-research-project を使って、/path/to/my-research をこのテンプレートへ移行してください。
元ディレクトリの.gitignoreを既定の読み取り除外規則とし、まず移す内容と移行先を提案してください。
```

現在の依頼だけでは、学習や新しい実験は始まりません。

## 移行の流れ

1. 元の`.gitignore`を確認し、除外されないファイル名を一つのディレクトリずつ調べます。
2. 必要な説明文、設定、コードの一部だけを読み、移す内容と移行先の対応表を`maintenance/MIGRATION.md`にまとめます。これは移行計画であり、まだ研究設定やコードの変更ではありません。
3. 日本語の要約を確認して承認します。承認済みの同じ変更について、繰り返し確認することはありません。
4. 必要な箇所をテンプレートの構造へ合わせて移し、関連テストと構成の検証を実施します。元ディレクトリは変更しません。

元のファイルが承認後に変わった場合は、その差を確認してから使用します。不明な研究条件や追加の読み取り範囲は、別途確認します。

## 何を移すか

| 元の内容 | 扱い |
| --- | --- |
| 研究目的、手法、次に確かめたい仮説 | 既存の目標・主張・実験候補の書式へ整理 |
| モデル、データ読み込み、評価計算のコード | 承認した箇所だけを既存の実行構造へ接続し、元の意味を保つテストを追加 |
| データの場所や分割方法 | `data/MANIFEST.json`へ記録。元データは外部に置いたまま |
| 必要な設定や依存ライブラリ | 対応する項目だけを整理。仮想環境のコピーや無断インストールはしない |
| 過去の結果、ログ、学習済み重み | 元の場所に残す。必要な知見だけ「未検証の過去情報」として整理 |
| 以前の承認、進行状態、Agent向け指示 | 引き継がない。このテンプレートの手順を使う |

## 読み取りのルール

`.gitignore`は、通常Gitで管理しないファイルを指定する除外規則です。このスキルでは、その規則に該当するファイルを既定で読みません。すでにGit管理されているファイルでも除外規則を優先し、下位ディレクトリの`.gitignore`も反映します。Gitリポジトリでなくても、元のルートに`.gitignore`があれば利用できます。

ルートの`.gitignore`がなければ、全ファイルを許可したとは扱わず停止します。必要な除外規則を人間が用意するか、読んでよいものだけをまとめた別ディレクトリを指定してください。Codexが規則を書き換えて読み取り範囲を広げることはありません。

除外されていなくても、隠しファイル、シンボリックリンク（別の場所への参照）、仮想環境、内包された別リポジトリ、ルート直下の`data`・`artifacts`・`references`などの実データ／成果物用ディレクトリは読みません。`src/project/data`のようなコード用のパッケージは区別します。ノートブックは実行結果を含むため、必要なコードを出力なしのテキストへ切り出して渡してください。

この除外判定は、移行用の補助プログラムが行うものです。`.gitignore`自体がOSやCodexアプリのアクセス権を変更するわけではなく、秘密情報の完全な検出も保証しません。元ディレクトリを指定する前に、除外規則を確認してください。追加で必要な除外ファイルがある場合は、その一件の扱いを明示的に相談します。

## 手動で確認する場合

テンプレートのルートで実行します。一覧はファイル名だけで、再帰探索は行いません。

```bash
python3 scripts/migration_source.py list --source "/path/to/my-research"
python3 scripts/migration_source.py list --source "/path/to/my-research" --path src
python3 scripts/migration_source.py read --source "/path/to/my-research" --path "src/model.py" --start-line 1 --lines 40
```

出力は一行の`OK migration-source ...`または`ERROR migration-source ...`です。本文は既定60行、最大120行で、出力全体は約6,000文字以内です。続きは`next_line`に示す行から読みます。一覧に続きがある場合は`next_offset`の値を`--offset`へ指定します。長いパスが多い場合は`--limit 10`などで一度に表示する件数を減らせます。

移行完了後、不足する初期設定があれば`$initial-setup`、準備が整えば`$plan-experiment`へ進みます。元の研究が動いていたことだけを理由に、新しい環境での動作確認や実験前の監査を省略しません。
