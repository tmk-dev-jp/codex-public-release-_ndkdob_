# 再現実験用のコミットとタグ

`$checkpoint-reproducibility` は、実験に必要な入力ファイルだけを選び、変更があればコミットを一つ作り、注釈付きタグを付けます。コード・設定・依存関係・データマニフェストの参照先をタグに記録します。変更がなければ現在のコミットを使います。同じ内容の同じタグは再利用し、既存タグを上書きしません。

リポジトリ直下から実行します。各オプションは複数指定できます。`EXP-ID` とコードの一覧は対象実験に合わせて置き換え、依存関係を固定したファイルがあれば `--dependency` で追加してください。

```bash
python3 scripts/reproducibility_checkpoint.py \
  --tag repro/EXP-ID-inputs \
  --path src/dl_research/training/trainer.py \
  --config configs/experiments/EXP-ID.json \
  --dependency pyproject.toml \
  --data-manifest data/MANIFEST.json
```

必要な固定済み計画も `--config` で追加してください。ディレクトリの一括指定、生データ・参照資料・成果物の追加、push は行いません。選択外のステージ済み変更や作業ファイルは維持します。選択ファイルが部分的にステージ済みの場合、進行中の merge/rebase、index ロックなどでは停止します。

タグから別の作業ディレクトリへチェックアウトし、記録した依存関係と利用者管理のデータを用意して再実行してください。タグだけでは外部データ・実際の環境・GPU ドライバー・乱数の決定性は保存されません。マニフェストのデータ識別情報と、再現に影響する未コミット変更がないことを確認する必要があります。

参照の公開直後にプロセスやディスクが停止すると index が古いままになる場合があります。コミット・タグ・選択ファイルの状態を確認してから再実行してください。タグを上書きして復旧しません。
